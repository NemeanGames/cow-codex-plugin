CODEX PLUGIN · v1.0.1

Continuity Of Work Ontology

Durable state, evidence, checkpoints, and reproducible records for resumable agent work.

Source on GitHub · Original release tag

Three skills

  • Work continuity: checkpoint, resume, record work, and inspect status.
  • Audit boundary: separate producer assertions from independent verification.
  • Research provenance: connect claims to evidence, transformations, and qualification state.

Install

Clone the repository and replace the example path below with the absolute path to your clone.

git clone https://github.com/NemeanGames/cow-codex-plugin.git
codex plugin marketplace add /absolute/path/to/cow-codex-plugin
codex plugin add cow@cow-local

Start a new Codex task after installation. Python 3.10 or later is required for the bundled runtime.

Check the runtime

From the repository root:

python plugins/cow/skills/cow-work-continuity/scripts/cow_cli.py model

What the status means

PASS, FAIL, UNKNOWN, ERROR, and NOT_RUN remain distinct. A producer assertion does not establish independent verification. R31, R39, and R41 remain UNKNOWN; no general efficiency, monetary-savings, or cross-domain reliability claim is established.

Release correction

Install v1.0.1 or current main. This release corrects a frozen-identity mismatch in the original Git source, adds startup identity enforcement, and removes unsupported commands. It uses a new semantic identity; old records are not silently migrated.

Release and privacy

The original annotated v1.0.0 tag and three-commit history are preserved. Publication fixes follow the tag on main. Historical audit records describe author-side checks. Private transcripts, research archives, credentials, and real execution records are excluded from this release.
