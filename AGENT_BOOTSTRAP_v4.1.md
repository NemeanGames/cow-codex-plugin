Use the authorized COW repository and preserve original references and history. Keep private research and real execution records in a separate local workspace. Preserve `README.md`, `.gitignore`, `LICENSE`, `AUDIT_LOG.json`, and this profile. Historical bootstrap commit:

The platform/model name does not establish an actual running session or tool grant. Discover actual execution capabilities once; record any unavailable mode rather than inventing an agent run. No manual user coding is required.

## Eight packets and ownership

Dispatch WP1–WP8 from `work_packets/`. Each packet has a dedicated branch/worktree and output root; no cross-packet edits or unrestricted subagent recursion. Freeze shared semantic/interface contracts before dependent implementation merges. Packet-local tests do not grant release-audit authority.

The aggregator alone merges after named gates, resolves interface changes through a decision receipt, and freezes the candidate. A separate independent auditor reviews that candidate and returns a sealed report. Failed audit triggers a new candidate revision, not a repaired artifact under the old hash.

This parallelism applies to code and offline tests. Live Unreal access is serial and separately authorized. No new editor or engine operation is authorized by this bootstrap.

## Network/dependencies

Record actual interpreter/provider versions. Use task-local environments and verified distributions. No global interpreter or engine installation. Core runtime validation/replay/audit/reporting must run offline after setup. Lock exact package versions and hashes before sealing. Missing license information blocks public redistribution, not unrelated private analysis.

## Deployment

Deploy only the sanitized `docs/` payload to GitHub Pages. Do not publish private source snapshots, real run data, host paths, location defaults, screenshots, or credentials. Check privacy and licensing before publishing; describe author-side checks accurately and do not imply independent audit. Record and verify an actual live URL; otherwise leave it null with a blocker. Do not claim deployment from a prepared workflow alone.

## Stops

Stop affected work on hash/source mismatch, path ownership conflict, missing required authorization, schema/semantic drift, dependency uncertainty, inaccessible baseline needed for a compatibility claim, or attempted production mutation. Preserve evidence. Never restart the entire investigation to recover a single missing binding.
